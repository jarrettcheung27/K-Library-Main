1. 根据用户提示，搜索指定latex文件内的待补充文献的标志upcite{xxx}/cite{xxx}。
2. 找到代补充文献位置后，根据该位置的前后文，总结出关键字，然后用web search 工具检索出与本文主题相关且包含关键字的文献。
3. 用文献校验api："https://api.crossref.org/works"去检验搜索到的文献的真实性。
4. 如果检验结果表示文献不存在，则重新搜索，如果迭代10次，依然无法找到合适的文献，则停止这个文献的寻找，并保留标志"{xxx}", 然后搜索下一个位置的文献。
